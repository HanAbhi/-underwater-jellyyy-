# Underwater Dreams 🪼

A tiny interactive ASCII-art ocean. Jellyfish drift through a deep-sea scene, their tentacles sway, and tapping or clicking one makes it dart away.

## Run it

No build tools or dependencies are needed.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. After GitHub finishes publishing, the site URL will appear in the Pages section.
